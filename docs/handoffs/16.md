# Handoff — module 16: drift containment and recovery

**Status: PARTIAL.** Drift classification, pool quarantine, halt, incident acknowledgement,
evidence-backed corrections, resolution, resume gating and reset-epoch rotation are
implemented. Acknowledgement never changes an economic fact or re-enables dispatch.

Owned paths:

- `packages/reconciler/src/drift.ts` and `drift.test.ts` — detection, quarantine, resume and
  reset gates.
- `packages/db/migrations/0011_reconciliation_and_recovery.sql` — incidents, append-only
  corrections and retained reconciliation evidence.
- `packages/db/src/journal/recovery.ts` — operational halt and owner-only recovery actions.
- `packages/db/src/journal/reconciliation.integration.test.ts` — equal-balance incomplete
  history, external drift quarantine and false human-resolution coverage.

The deterministic tests and PostgreSQL cases passed. Incomplete history quarantines even
when balances match. External activity is stored as `UNEXPLAINED`, not assigned to a
strategy. Resume requires the latest COMPLETE reconciled cut for the same stable account,
zero active incidents and zero unresolved dispatch liabilities. Epoch rotation additionally
requires a positive reset incident and sender fencing, and closes rather than deletes the old
epoch.
