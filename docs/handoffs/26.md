# Module 26 — Observability and adversarial security

**Status: PARTIAL**

The central operational signals use a fixed-cardinality bigint registry. API responses apply a
restrictive security-header set, non-local deployments add HSTS, and Fastify rejects bodies
above 64 KiB. The threat model and read-only unknown-order runbook identify authority, replay,
injection, source degradation and restore risks.

## Verification and limits

Unit tests prove allowed metric labels, reject arbitrary asset/account/plan dimensions, exercise
alert thresholds and check the header policy. Existing secret-boundary and layering checks cover
raw secret and principal imports. The hardened Compose contract proves separated mounts and uids
by configuration inspection.

No external security audit is claimed. Host-level hostname egress enforcement, live credential
isolation, ingress rate limiting, authenticated export authorization, webhook destination
policy, UI CSP compatibility and a full independent exploit review remain release blockers.
