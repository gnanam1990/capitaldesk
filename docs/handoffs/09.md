# Handoff — module 09: deterministic planner

**Status: COMPLETE for the v1 preview path.** A pure planner turns a frozen eligible cohort
into one transparent LIMIT IOC child, an explicit conflict, or no order. It performs no I/O
and has no capital-mutation capability.

## Owned paths

- `packages/planner/src/planner.ts` — eligibility, direction, strict price, venue-filter,
  fixed-FIFO and residual algorithm.
- `packages/planner/src/planner.test.ts` — eight deterministic behavior cases.

The planner removes expired, superseded, deferred, unauthorized, stale-policy, wrong-scope
and zero-delta rows before direction evaluation. Opposite eligible directions return
`CONFLICT`; no internal fill is created. Same-side rows sort by database accepted sequence,
then stable identity. BUY prices round down and SELL prices round up to the verified tick;
aggregate quantity rounds down to lot step. The result names every allocation, cap, residual,
exclusion and cohort cutoff.

TypeScript passed and all 8 planner cases passed. No venue call is owned by this module.
