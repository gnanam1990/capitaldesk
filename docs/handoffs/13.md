# Module 13 — Durable dispatch

Status: **COMPLETE for the local journal and simulator boundary**

`DispatchRepository.markAuthorized` locks the pool, attempt, and plan; invokes approval
revalidation and the executor signer; then commits `DISPATCH_MARKED`, the exact signed
request, host-fence evidence, and a `dispatch.send` outbox message with `max_attempts = 1` in
one serializable transaction.

`DispatchConsumer` claims that message once, validates the persisted request, commits
`SEND_ATTEMPTED` before the first network byte, performs one fetch, and durably classifies
the result. HTTP 2xx becomes `ACKNOWLEDGED`; decisive 4xx becomes `REJECTED`; transport loss,
408, 418, 429, and 5xx become `UNKNOWN`. It never retries or re-signs.

Focused tests cover the database marker rollback/immutability contract and the consumer's
send ordering, one-call bound, ambiguous response handling, and malformed-payload refusal.
