# Handoff — module 14: authoritative fills, fees and allocation

**Status: PARTIAL.** The complete-evidence reducer now freezes approved FIFO gross-base
ownership and solves quote/commission atom rounding with a pinned deterministic
lower-bounded circulation. It conserves every source row, enforces cumulative strategy and
fee caps, and refuses unsupported or infeasible fee evidence without creating ownership.

Owned paths:

- `packages/ledger/src/fill-allocation.ts` — `fifo-circulation-v1` reducer using bigint-only
  rational arithmetic and deterministic graph ordering.
- `packages/ledger/src/fill-allocation.test.ts` — golden 500/500 partial fill, multi-price
  FIFO crossing, row conservation, combined quote cap, unsupported fee and SELL base-fee
  cases.
- `packages/db/migrations/0011_reconciliation_and_recovery.sql` — immutable final allocation
  rows plus deferred source conservation.
- `packages/db/src/journal/reconciliation.ts` — atomic allocation, ledger posting, intent/plan
  projection and residual reservation release.

The 5 reducer cases, package typecheck and 4 PostgreSQL 17.10 reconciliation/recovery cases
passed. The PostgreSQL golden case produced A and B claims of exactly `300801000 USDT:v1 +
1000000 BTC:v1` after quote commission and released only each proven remainder.

The general solver still lacks the specification's independent exhaustive 5x2 oracle and a
property suite over arbitrary matrices. Third-asset fees require an explicit reserved cap;
real BNB routing remains disabled by ADR-0010. No actual venue fill was observed, so this is
deterministic and real-database evidence only.
