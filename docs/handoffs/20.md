# Module 20 handoff — proposal agent tools

**Status: PARTIAL**

## Implemented

- New `@capitaldesk/agent-tools` package with the six CapitalDesk-owned read/propose tool names
  and closed JSON schemas. No approval, allocation-write, signing, dispatch, shell, endpoint or
  credential tool exists.
- `ProposalToolRouter` permanently binds workspace, pool and strategy identity outside tool
  input. Extra identity/endpoint fields are rejected and proposal writes use the SDK's real API
  route without automatic retry.
- Strategy-scoped intent, target-progress and participating-plan reads keep agent queries within
  the credential's fixed strategy.
- Two explicit deterministic reference profiles (`strategy-a` accumulate and `strategy-b`
  reduce) consume exact permitted price observations. Untrusted context cannot affect targets,
  permissions, routing or rationale. The rationale states that this is a coordination
  demonstration and makes no market-alpha claim.
- Broker-key disclosure states that testnet funds are separate from Agentic OAuth. Approved-host
  status remains `BLOCKED` as recorded by module 00.
