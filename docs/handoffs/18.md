# Module 18 handoff — workers, events and webhooks

**Status: PARTIAL**

## Implemented

- Append-only, tenant-scoped domain event stream with monotonic cursor and `Last-Event-ID`
  catch-up formatting.
- Distinct `job.reconcile`, `job.ingest`, `job.export` and `job.webhook` types. Reconciliation
  is prioritized; claims use leases and `SKIP LOCKED`; `dispatch.*` is excluded from this
  retryable worker queue.
- Durable webhook endpoint/delivery schema with delivery identity, bounded attempts, leases,
  terminal/dead-letter states and secret references rather than values.
- Exact-body HMAC envelope, timestamp tolerance, rotating-secret verification, capped webhook
  backoff and DNS/IP destination checks that refuse credentials, non-HTTPS, private, loopback,
  link-local and mixed public/private answers.
- A one-job scheduler boundary that invokes only typed retryable worker handlers, acknowledges
  under the same lease, records redacted failures for bounded retry and reports lease loss.
