# Module 22 — Capital and strategies UI

**Status: PARTIAL**

Asset-first capital, strategy claims, HOUSE, reservations, quarantine, selected symbol, absolute targets, proposal credential metadata and drift evidence are implemented as responsive views. Setup/allocation/credential mutations remain disabled until their owner API and typed SDK contracts land.

## Files

- `apps/web/src/app/capital/page.tsx`
- `apps/web/src/app/strategies/page.tsx`
- shared module 21 shell/components/styles and `apps/web/src/lib/preview-data.ts`
- `apps/web/src/app/ui-contract.test.ts`

## Behavior

The capital table never combines assets. Exchange totals and internal claim buckets remain separate columns; quarantine is non-spendable. HOUSE is explicit. Strategy cards explain that a proposal identity is not an exchange wallet and show secret references only.

## Verification and evidence

The module 21 targeted typecheck, 73 web tests, lint and production build cover these routes. The preview model test checks canonical decimal strings, zero balances, fee-only quarantine and long IDs. No PostgreSQL, authenticated owner flow or venue evidence is claimed in this frontend branch.

## Blockers

Account discovery/baseline creation, allocation writes, token rotate/revoke and live source-lag records need the completed module 17–20 SDK contracts. The routes show the missing boundary instead of fixture data unless preview mode is explicitly enabled.
