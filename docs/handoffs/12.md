# Module 12 — Isolated executor

Status: **PARTIAL — executable local/testnet boundary; deployment isolation proof pending**

The executor now owns the sole `VENUE_TRADE` signer. It can produce only Binance Spot
`POST /api/v3/order` requests with `LIMIT` + `IOC`, a unique approved client order id, and a
bounded `recvWindow`. The request is checked against the sealed plan and active owner
approval, signed inside the serializable marker transaction, and persisted as immutable
bytes. The outbox consumer receives no credential and no signing function.

Proof in `apps/executor/src/approved-marker.test.ts` and `binance-write.test.ts` covers exact
plan-field binding, malformed inputs, fixed endpoint/method/type/time-in-force, deadline
envelopes, and no network call before the durable send-attempt marker.

The repository does not yet contain independently observed production egress/IP evidence or
a funded venue execution. Production writes remain disabled by configuration and policy.
