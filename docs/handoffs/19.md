# Module 19 handoff — SDK and operator CLI

**Status: PARTIAL**

## Implemented

- New `@capitaldesk/sdk` with pool, plan, ledger, proposal, exact approval and reconciliation
  operations. Every request makes one fetch only; economic writes are never automatically
  retried, and plan uncertainty states remain unchanged.
- Independent evidence verifier recalculates gross allocation and per-asset commission totals
  from exported rows using bigint atom strings.
- Machine-JSON operator CLI for doctor, pool, plans, ledger, approve and reconcile. Approval
  requires explicit workspace, pool, plan, digest, execution mode and idempotency key.
- Authentication is read from a `file://` reference. Passwords, secrets, private keys and
  signing keys are rejected as command-line options. Exit code 2 is a CLI/config error and 3
  is an HTTP refusal.
