observed live.

## Contract changes for dependants

- Environment contracts fail closed: no defaults, allowlisted venue hosts per environment,
  write capability starting disabled and impossible to enable in `production-read-only`.
- Three credential classes bound to process roles (ADR-0007). A credential variable in the
  wrong role refuses startup by name.
- Dependency layering and the credential boundary are enforced by commands that were verified
  to fail on injected violations.
- Migrations are forward-only, immutable once applied, read-only to inspect, and refuse a
  divergent history. There is no reset command.
