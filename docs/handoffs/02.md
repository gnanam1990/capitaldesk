## Acceptance gate

> No decision or money path uses a JavaScript number, or a boolean to collapse distinct
> uncertainty states.

Met. Quantities are bigint atoms bound to an asset identity; prices are exact fixed point;
canonical JSON refuses numbers outright so a quantity cannot lose precision in transit. Lint
bans `parseFloat` and `Math.round` workspace-wide. Uncertainty is never a boolean: dispatch
outcome, venue observation, accounting completeness, coverage state and fee bound status are
each their own enumeration with more than two values.

## Contract changes for dependants

- **Frozen digest field list.** `PLAN_DIGEST_BOUND_FIELDS` is both the digest input and a
  runtime allowlist, so adding a field to the payload type without adding it here makes every
  payload carrying it fail loudly rather than hash to a stale digest.
- **Amended state machines.** Dispatch attempts gain `SEND_ATTEMPTED`, `NOT_SENT_PROVEN` and
  `IRRECOVERABLE_UNCERTAINTY` (ADR-0001). Venue observations gain `EXPIRED_IN_MATCH`,
  `PENDING_CANCEL` and `UNSUPPORTED_OBSERVATION` (ADR-0004).
- **Capability gates that refuse by default.** `assertFeePolicyDispatchable` requires a
  derivation supplied at call time, and no shipped policy can authorize a dispatch today
  (ADR-0010). `assessCoverage` requires a proven movement universe (ADR-0002).
- `mayAutomaticallyResend` returns false in every state. `mayReleaseUnusedReservation`
  requires terminal status, reconciled accounting and complete coverage together.
